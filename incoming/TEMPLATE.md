# Hồ sơ MythicMobs

## Môi trường

- Project và case —
- Nguồn YAML, revision hoặc ngày lấy bản sao —
- Minecraft, nền server và build, Java —
- MythicMobs phiên bản/build và Free/Premium —
- Addon liên quan và phiên bản, hoặc ghi không dùng —

## Cấu hình và yêu cầu

- Đường dẫn bản sao và vị trí gốc tương đối —
- ID mob, skill gốc và các ID/file được tham chiếu —
- Hành vi mong muốn —
- Trigger, target, telegraph/animation, thời điểm và vùng trúng đòn —
- Cooldown, điều kiện hủy, cleanup, reset và multiplayer nếu áp dụng —
- Nguồn wiki hoặc changelog, mục liên quan và ngày đối chiếu —
