# MM-2026-001 — Lỗi mã hóa đầu ra khi kiểm tra YAML trên Windows

- Mã case — MM-2026-001
- Ngày — 13/11/2026
- Project — MythicMobs-AI-Training
- Phiên bản plugin — Không áp dụng. Tái hiện với Python 3.12 và PyYAML 6.0.3 trên Windows.
- Yêu cầu ban đầu — Chạy trình kiểm tra cú pháp để đọc hai file YAML ví dụ và ghi trạng thái theo bằng chứng.
- File bản lỗi — [tests/check_yaml.py](../../tests/check_yaml.py), khi gọi `python tests/check_yaml.py examples` với stdout dùng `cp1252`.
- Hiện tượng thực tế — Parser in `OK` cho hai file rồi Python báo `UnicodeEncodeError` ở dòng tổng kết và trả mã thoát 1. Traceback chỉ ra `cp1252` không mã hóa được chữ `Đ`.
- Điều người dùng muốn — Bằng chứng kiểm tra cú pháp có thể tái lập trước khi kiểm tra server.
- File bản sửa — [tests/README.md](../../tests/README.md) ghi lệnh `python -X utf8 tests/check_yaml.py examples`.
- Nguyên nhân đã xác nhận — Khi stdout dùng `cp1252`, bước in tiếng Việt thất bại sau khi đọc YAML. Cùng file và parser, bật UTF-8 cho Python thì in được tổng kết.
- Nguyên tắc tái sử dụng — Dùng chế độ UTF-8 khi chạy công cụ có đầu ra tiếng Việt trong môi trường Windows dùng code page cũ.
- Kiểm thử hồi quy — Chạy lại với `-X utf8`. Quan sát hai dòng `OK`, tổng kết 2 file và 0 lỗi, mã thoát 0.
- Trạng thái — `syntax-checked` cho hai file ví dụ. Bằng chứng của case này thuộc công cụ parse YAML.
